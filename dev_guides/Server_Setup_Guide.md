# Server Setup

This is a guide to set up the API to be accessible by setting up a server for it.

There are two kinds of set up that I have documented below:
1. Local Server
2. Publicly accessible Server

### 1. Local Server

#### Step 1: Set up environment
Make sure you have Python installed (`python --version` to check).
Use a virtual environment to manage dependencies. Follow the steps in [Env_Setup_Guide.md](Env_Setup_Guide.md)

#### Step 2: Add dependencies
Add the following dependencies. Ignore this if already done.
```commandline
pip install flask
pip install flask-cors
```

#### Step 3: Write API
In the main file (in case of this project, it is `Lisn2MeAPI.py`), write atleast one API.
For example:
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/')
def home():
    return "Hello, API!"

@app.route('/api/data', methods=['GET'])
def get_data():
    return jsonify({"message": "Here is your data"})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```

#### Step 4: Run the local server
```commandline
python Lisn2MeAPI.py
```

#### Step 5: Test it
With curl:
```commandline
curl http://127.0.0.1:5000/api/data
```
Through Browser:
Type in the URL (http://127.0.0.1:5000/api/data) in the browser address bar and run it.

Through Postman:
You can also set up Postman GET request service to test it.

### Publicly accessible server

#### Prerequisite:
Although this is not mandatory, but this is a good to have:
Get a static IP from your network. This can be done by calling up your ISP and requesting them for a static IP for your network. This may cost a small amount of extra fee per month to the ISP.

#### Step 1: Local Server set up
Complete all steps from Local Server set up above.

#### Step 2: Add `ngrok` dependency
Add `ngrok` to your `requirements.txt` file, or run the following command:
```commandline
pip install pyngrok
```

#### Step 3: Authenticate with `ngrok`
Visit `ngrok` website and do either of the two:
Login - https://dashboard.ngrok.com/login/sso
Sign up - https://dashboard.ngrok.com/signup

#### Step 4: Add authtoken
Run the following command to add your authtoken to the default `ngrok.yml`
```commandline
ngrok config add-authtoken <your secret token generated by ngrok>
```

#### Step 5: Run local server
Make sure the local server is running on a separate terminal.
The command to run the local server is:
```commandline
python Lisn2MeAPI.py
```
where `Lisn2MeAPI.py` is your main file.

#### Step 6: Get your domain
Navigate to `Setup and Installation` on the `ngrok Dashboard`.
Then navigate to the bottom under the header `Deploy your app online`
Then switch to the option `Static Domain`.
It will show you a command which is as follows:
```commandline
ngrok http --url=<Your new static domain> 80
```
Copy it.

#### Step 7: Start the publicly accessible server
Copy the command above and paste it in a new terminal while keeping the local server running.
Run it.

#### Step 8: Test it
You can test this on a different laptop or mobile or any other device with access to open internet.
You can test it with the following means:
With curl:
```commandline
curl <your static domain>/api/data
```
Through Browser:
Type in the URL (<your static domain>/api/data) in the browser address bar and run it.

Through Postman:
You can also set up Postman GET request service to test it.
